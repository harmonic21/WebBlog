# WebBlog

## Сборка приложения

*Осуществляется с помощью maven + версия java не ниже 17*. Для сборки необходимо:
1. Перейти в директорию c pom.xml. Осуществить clean install или выполнить команду "mvn clean install"
2. После этого в директории target будет создан war файл web-blog-app.war.

Для запуска war файла необходимо скачать контейнер сервлетов Apache Tomcat. Pекомендуется версия 11.0.
Необходимо скопировать web-blog-app.war и поместить его в директорию Tomcat 11.0/webapps
После запуска Apache Tomcat можно перейти на страницу http://localhost:8080/web-blog-app/

## В приложении есть возможность:
1. Добавить пост с помощью кнопки "добавить пост"
2. При добавлении поста вписать его название, содержимое, расставить теги, прикрепить изображение
3. После создания поста можно поставить ему лайк:)
4. Нажав на название поста можно оставить к нему комментарий(Указав имя автора и текст комментария). Их количество отображается рядом с лайками.
5. На главной странице реализована пагинация - можно указать номер и размер страницы
